1. Общие положения

Настоящая Политика конфиденциальности описывает обработку информации при использовании мобильной игры «Meze: Лабиринты» (далее — Игра).

2. Информация, сохраняемая Игрой

Для использования текущей Android-версии Игры не требуется регистрация или предоставление имени, номера телефона и электронной почты.

На устройстве могут сохраняться:

  • прогресс кампании и результаты прохождения уровней;
  • игровые монеты, опыт, звёзды и рекорды;
  • разблокированные предметы и элементы оформления;
  • настройки игры, звука и обучения;
  • выбор пользователя относительно рекламы;
  • технические записи о рекламных вознаграждениях.

Технические записи о рекламных вознаграждениях могут содержать идентификатор попытки, размер бонуса, сведения о завершённом уровне и статус подтверждения награды.

Они используются для восстановления заслуженных игровых монет и предотвращения их повторного начисления.

3. Локальное хранение

В проверенной Android-версии прогресс и настройки хранятся локально на устройстве пользователя.

Собственный сервер разработчика для синхронизации игрового прогресса не используется.

При удалении Игры или очистке её данных локальные сохранения могут быть утрачены.

4. Рекламные технологии

В Игре используется Yandex Mobile Ads SDK для отображения рекламных объявлений.

При использовании рекламных функций сторонний поставщик рекламных технологий может получать техническую информацию, связанную с устройством, сетевым соединением и рекламными событиями.

При установлении сетевого соединения удалённым серверам может быть доступен IP-адрес подключения.

В проверенной конфигурации Android отсутствует разрешение доступа к рекламному идентификатору Google, а получение координат устройства через разрешения геолокации отключено.

Это не исключает обработку иных технических идентификаторов и сведений рекламной системой.

5. Цели обработки информации

Локальные игровые сведения используются для следующих целей:

  • сохранение и восстановление игрового прогресса;
  • учёт виртуальных монет и игровых предметов;
  • сохранение пользовательских настроек;
  • корректное начисление рекламных вознаграждений;
  • предотвращение повторного начисления наград.

Рекламные технологии используются для предоставления рекламных объявлений и связанных с ними операций.

Правовые основания обработки персональных данных должны определяться отдельно для каждой применимой категории данных и цели.

6. Управление рекламой

В текущей версии Игры пользователь может управлять разрешением на работу рекламных функций.

При отсутствии соответствующего разрешения собственный рекламный адаптер Meze не инициирует загрузку рекламных объявлений.

Пользователь может изменить ранее сделанный выбор через предусмотренные настройки Игры.

Отзыв разрешения не означает автоматического удаления сведений, ранее переданных стороннему поставщику рекламных технологий.

При необходимости согласие на обработку персональных данных оформляется отдельно от принятия Пользовательского соглашения.

7. Хранение и удаление данных

Локальные данные Игры сохраняются на устройстве до их удаления или замены соответствующими операциями сохранения.

Пользователь может очистить данные приложения средствами Android или удалить Игру с устройства.

Действие внутриигровой функции сброса прогресса определяется её текущей реализацией и не обязательно охватывает данные сторонних рекламных сервисов.

Для обращения по вопросам обработки и удаления персональных данных можно использовать контактный адрес разработчика.
