Политика конфиденциальности

Редакция 0.2 · Проект для проверки

Документ находится на этапе подготовки. Рекламная конфигурация для приложения 0+ проходит проверку. Окончательная редакция будет опубликована перед выпуском игры.

1. Общие положения

Настоящая Политика конфиденциальности описывает обработку информации при использовании мобильной игры «Meze: Лабиринты» (далее — Игра).

2. Информация, сохраняемая Игрой

Для использования текущей Android-версии Игры не требуется регистрация или предоставление имени, номера телефона и электронной почты.

На устройстве могут сохраняться:

  • прогресс кампании и результаты прохождения уровней;
  • игровые монеты, опыт, звёзды и рекорды;
  • разблокированные предметы и элементы оформления;
  • настройки игры, звука и обучения;
  • сведения о принятии условий и необходимые настройки конфиденциальности;
  • технические записи о рекламных вознаграждениях.

Технические записи о рекламных вознаграждениях могут содержать идентификатор попытки, размер бонуса, сведения о завершённом уровне и статус подтверждения награды.

Они используются для восстановления заслуженных игровых монет и предотвращения их повторного начисления.

3. Локальное хранение

В проверенной Android-версии прогресс и настройки хранятся локально на устройстве пользователя.

Собственный сервер разработчика для синхронизации игрового прогресса не используется.

При удалении Игры или очистке её данных локальные сохранения могут быть утрачены.

4. Рекламные технологии

Для Android-версии Игры готовится использование Yandex Mobile Ads SDK для показа неперсонализированных рекламных объявлений. Релизная конфигурация и её соответствие требованиям для приложений 0+ проходят проверку.

При использовании рекламных функций сторонний поставщик рекламных технологий может получать техническую информацию, связанную с устройством, сетевым соединением и рекламными событиями. По сведениям поддержки Яндекса, SDK по умолчанию собирает IP-адрес, технические характеристики устройства и идентификаторы установки. Состав данных в детском режиме уточняется.

При установлении сетевого соединения удалённым серверам может быть доступен IP-адрес подключения.

В проверенной конфигурации Android отсутствует разрешение доступа к рекламному идентификатору Google, а получение координат устройства через разрешения геолокации отключено.

Это не исключает обработку иных технических идентификаторов и сведений рекламной системой.

5. Цели обработки информации

Локальные игровые сведения используются для следующих целей:

  • сохранение и восстановление игрового прогресса;
  • учёт виртуальных монет и игровых предметов;
  • сохранение пользовательских настроек;
  • корректное начисление рекламных вознаграждений;
  • предотвращение повторного начисления наград.

Рекламные технологии планируется использовать для показа неперсонализированной рекламы, учёта показов и работы форматов рекламы, включая вознаграждение.

Обработка персональных данных для ответа на обращения осуществляется для рассмотрения запроса и направления ответа. Для рекламной обработки в качестве предполагаемого основания рассматривается отдельное согласие. Его применимость и фактический состав операций подлежат проверке до выпуска.

6. Управление рекламой

Для Игры 0+ предусматривается неперсонализированная реклама. Персонализированная реклама и выбор её персонализации не предусмотрены.

Необходимость согласия на обработку данных для показа рекламы, его содержание и порядок получения определяются после проверки фактической обработки и применимых правовых оснований.

Если обработка основана на согласии, пользователь или его законный представитель может отозвать его, обратившись к разработчику.

Отзыв согласия не означает автоматического удаления сведений, ранее переданных стороннему поставщику рекламных технологий.

При необходимости согласие на обработку персональных данных оформляется отдельно от принятия Пользовательского соглашения.

7. Хранение и удаление данных

Локальные данные Игры сохраняются на устройстве до их удаления или замены соответствующими операциями сохранения.

Пользователь может очистить данные приложения средствами Android или удалить Игру с устройства.

Действие внутриигровой функции сброса прогресса определяется её текущей реализацией и не обязательно охватывает данные сторонних рекламных сервисов.

Обращения пользователей и сведения, необходимые для ответа, хранятся в течение срока рассмотрения обращения и далее при наличии оснований, установленных законом. Сроки хранения у Яндекса определяются его политикой конфиденциальности. Для обращения по вопросам обработки и удаления данных можно использовать контактный адрес разработчика.

8. Сторонние сервисы

При просмотре рекламного объявления пользователь может перейти на внешний сайт или в другое приложение.

На таких ресурсах могут действовать собственные правила обработки информации.

Условия обработки данных Яндексом описаны в его политике конфиденциальности. Получатели, состав данных и сроки обработки для детского режима уточняются.
